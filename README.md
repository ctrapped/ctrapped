## Hi, I'm Cameron 👋

I build data and machine-learning pipelines for large physics simulations. I'm a postdoc in
Physics & Astronomy at Johns Hopkins University, working with the FOGGIE and FIRE galaxy-simulation
collaborations. More at [ctrapped.github.io](https://ctrapped.github.io/).

**Tools:** Python · PyTorch · NumPy/h5py · pytest · GitHub Actions · C++ · C

### Projects

- **[CoNNGaFit](https://github.com/ctrapped/CoNNGaFit)**: a 3-D convolutional neural network that
  learns how the gas in a galaxy is moving from telescope-style images created from state-of-the-art
  simulations. It ships with a demo that trains on a laptop CPU in about a minute.
- **[VeryObservableFIRE](https://github.com/ctrapped/VeryObservableFIRE)**: turns galaxy simulations
  into realistic synthetic radio-telescope observations and saves underlying physics information at
  each pixel. This can be used as training data for simulation-based inference (training ML models on
  simulated data so they can be applied to real data).
- **[Clump finder](https://github.com/foggie-sims/foggie/tree/master/foggie/clumps/clump_finder)**:
  finds small gas structures around simulated galaxies. Existing tools were too slow at this scale or
  simply could not run at the scale of our simulations. 
- **[Mock HI imager](https://github.com/foggie-sims/foggie/tree/master/foggie/galaxy_mocks/mock_hi_imager)**:
  measures how much gas real telescopes would miss because of sensitivity and resolution limits.
- **[Enzo](https://github.com/foggie-sims/enzo-foggie/tree/main)**: adding fast, approximate
  light-propagation physics (radiative transfer) to a large open-source C++ simulation code.
- **[IFU → grism](https://github.com/foggie-sims/foggie/tree/master/foggie/galaxy_mocks/ifu_to_grism)**:
  converts simulated 3-D spectral data into the images a different type of telescope instrument records.
